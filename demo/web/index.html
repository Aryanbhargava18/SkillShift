Does a malicious-skill detector learn the source, or the threat?

Paste a SKILL.md below. Two text detectors score it: one trained on the whole merged benchmark — which quietly keys on each source's writing style and over-blocks — and one trained only on sources that contain both benign and malicious skills, which forces it to read content instead of style. Both are compact versions of the paper's linear baseline (word TF-IDF + logistic regression, 30k-term vocabulary instead of 200k), running entirely in your browser. no server · nothing to wake up

Try an example:

On 400 unlabeled public GitHub skills, the all-data detector flags about 30% as malicious and the fixed one about 5% — most of that gap is the all-data model reacting to how a source writes, not to anything harmful. The fix removes most of the false alarms, at the cost of some recall. That trade is the point: a detector that silently learns "which dataset is this from" looks strong on a random split and quietly over-blocks in the wild.
